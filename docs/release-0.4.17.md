# 0.4.17 自检与交付记录

## 已修复

- 更新源指向失效或私有 GitHub Release，未登录客户端无法下载。改为 LynShen / Monoize 双域名。
- Windows 后台自动安装可能退出软件。现在先下载验签，用户确认后保存工作区并安装。
- Windows 用户目录读取不一致，导致更新设置未生效。统一使用应用配置目录函数。
- 更新换源时进度和旧错误残留。换源重置进度，并要求备用包版本完全一致。
- CLI 发布来源不固定。现在固定提交与版本，随桌面安装包发布。
- 软件内账号密码注册登录。替换为浏览器设备授权，网站批准后发放独立凭据。
