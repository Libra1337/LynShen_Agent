0.4.23 稳定版更新公告

- 新增 右上角进度卡片：自动显示待办和子智能体列表，每个子智能体正在做什么一目了然，点开可实时查看它的完整过程
- 新增 对话里的子智能体卡片，取代原来的工具行
- 新增 计划模式：先调研再出计划，计划以卡片展示（支持表格），可选模式批准执行，或提出修改
- 新增 生图：智能体可以画图和改图，设置 → 模型 可选生图模型
- 新增 侧栏可收起为图标栏，左下角账户卡片（余额、套餐、用量、设置、主题、退出），去掉齿轮按钮
- 新增 背景图覆盖整个窗口，设置里新增「玻璃透明度」，侧栏、标题栏、输入框等大面板可调成毛玻璃
- 新增 反馈问题改为提交工单，进度和回复可在控制台「工单」页查看
- 优化 动画与过渡全面重做：统一节奏，去掉缩放，菜单和对话框淡入淡出，消息柔和出现，拖动窗口时不再抖动
- 优化 模型列表一个模型一行，有多个分组或线路时点进去选择
- 优化 macOS 图标改为圆角
- 修复已知问题
