0.4.24 稳定版更新公告

- 新增 Auto 模型：由管理员在网关指定，可以是任何模型，按该模型的价格计费
- 新增 网关新上架的模型自动出现在模型列表里，无需手动勾选
- 新增 审批卡片支持快捷键：1 允许一次，2 始终允许，3 或 Esc 拒绝
- 新增 窗口在后台时，有命令等待批准或计划等待确认会发系统通知
- 新增 账户卡片的「最近 60 秒」RPM、TPM 和缓存命中显示真实数据
- 新增 支持显示 LS-Auto 等模型的思考过程
- 优化 运行中发送的消息直接进入当前这一轮，不再打断正在执行的命令
- 优化 模型列表一个模型一行，模型菜单去掉重复的思考强度和小字
- 优化 对话栏改为固定宽度；侧栏只保留左上角一个收起按钮
- 优化 长回答输出更流畅，长时间使用占用内存更少
- 修复 「还原此文件」会连同你自己没提交的改动一起删掉，现在只撤销智能体的修改
- 修复 新对话偶尔显示「该对话已关闭」
- 修复 Windows 上对话页面空白，以及勾选的模型不显示
- 修复 背景图模式下左上角的白边和底部毛玻璃挡住最后一行
- 修复已知问题
